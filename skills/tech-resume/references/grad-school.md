# 研究所申請用 CV（課程型、應用型碩士）

這份不是原書內容。它整理自 2026-10 查核加拿大三個課程型碩士官方申請頁時得到的共通做法（UofT MScAC、UofT MEng ECE、Waterloo MEng ECE Co-op）。**各學程官方規定永遠優先**；每次申請前重新查一次。

## 和求職履歷的差別

| 面向 | 求職履歷 | 研究所 CV |
| --- | --- | --- |
| 讀者 | recruiter、hiring manager | 招生委員會、面試官、推薦人 |
| 最先看的 | 年資、技術、職稱 | 學位、學校、成績、先修課程 |
| 段落順序 | 經歷在前 | 教育在前，接著經歷、獎項、專案 |
| 課程 | 通常不寫 | 列出對應學程先修的課與成績 |
| 用途 | 換面試 | 審查依據 + 面試題庫 + 推薦人參考底稿 |

成果寫法（具體、有判斷、不灌水）與格式規則照舊適用。

## 先查官方規定

每個學程都要查這幾項，不要互相套用：

- CV 是否必繳、頁數上限（例：有學程寫 1–2 頁，有學程完全沒寫）
- 上傳格式、檔案大小、檔名限制（例：只收特定格式、不得有括號或引號）
- 送出後能不能修改（有些學程送出即定稿，連結與錯字都改不了）
- 成績採計口徑：最後一年、最後兩年，還是全程平均；國際學歷可能另有規定
- 官方建議 CV 包含的項目：發表要完整引用、課程專案（例如 capstone）歸在專案而非工作經歷

## 成績怎麼寫

- 用原始分制（例如台灣百分制 `82.64/100`），不要自行換算成 4.0；官方等值表通常直接用原分制比較。
- 成績單有印官方平均，就照抄並與成績單完全一致。
- 自己算的分段平均（major、最後兩年）可以補充，但必須：標明 self-calculated、寫出採計範圍（學分數、哪些課）、排在官方或累計平均之後。只列 major 平均容易被看成選擇性呈現。
- 學程看「最後一年」時，若最後一年學分很少，要先問學程怎麼認定，再決定強調哪個數字。
- 課程名稱照英文成績單原文；非本系開的課不要歸到「本系核心課」底下——審查者會拿成績單課號對照。

## 課程區

- 依目標學程的先修要求分組（例如演算法、作業系統、資料庫這類學程點名的課放最前面）。
- 研究所等級課程（大學部修的碩士班課）單獨一行，是很強的訊號。
- 在學申請：列出送件後還在修的課（有些學程明文要求）。

## 經歷與專案

- 課程內完成的專案放在 Projects 或 Education，不放 Work Experience。
- 研究經歷寫出題目、指導者或主管、你的貢獻與結果；面試會逐條追問，每一句都要能口頭解釋給非專業人士聽。
- 團隊專案寫清楚分工（`co-developed with one teammate`），不要寫成個人主導。
- 數字只放能解釋來源與分母的；忘記分母的百分比寧可刪掉。
- 不能點開或已失效的 demo 不放；改連公開 repo，README 開頭補英文摘要。

## 不放或另外處理

- 語言考試成績：通常由考試機構另外送分，CV 不必列。
- 證照：寫在 CV 即可；學程說不需要的額外文件不要另外上傳。
- 推薦人資訊：走申請系統，不寫在 CV。

## 一致性

CV、短文（statement of intent／essays）、推薦信、面試要講同一個故事。CV 是推薦人的參考底稿，也是面試題目的來源；短文提到的每個經驗，在 CV 上都要找得到對應的一行。
