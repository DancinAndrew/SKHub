# 外部查證規範（只查會過期或可驗證的事實）

## 要查什麼

只查這幾類，而且只查會影響理解的：

- 數字：市場規模、財務數據、成長率、價格、匯率、利率、基準測試分數。
- 日期與時序：發表、上市、政策生效、事件發生的時間。
- 現況：公司、產品、人物職位、法規或訴訟目前的狀態。
- 講者引用的研究、報告、官方說法。

不查：

- 講者自己的觀點、預測、比喻。照實記成「講者認為…」，預測加上說話日期。
- 課程裡的基礎定義與教科書內容（除非講者明顯說錯）。

## 來源等級

1. 官方標準、主管機關、政府、公司財報與官方文件。
2. 同儕審查論文、原始研究、官方技術報告。
3. 第一方的工程部落格、原始資料集。
4. 有信譽的專業媒體（沒有原始來源時才用）。

不用內容農場、匿名整理、轉貼、搜尋結果摘要當證據。

## 規則

- 一般外部事實維持至少 2 個可靠且獨立來源；同一上游或同一家公司的兩頁不算兩個獨立觀點。主管機關發布的制度條文、官方統計表或第一方產品規格，可以用一份直接負責該事實的原始文件核對該範圍，須在 callout 明寫「官方原始文件」，或用「財務省原聲明／BIS 原調查」等連結名稱明確識別原始性，並說明支持範圍；這不能證明動機、因果或預測。不要為湊兩條連結加入無關文件。
- 統計、法律、醫療、市場數據要確認發表日期、範圍與目前是否適用；會變的資訊寫明確日期。
- 分類處理：
  - **已確認**：可靠且獨立來源一致，或直接適用的官方原始文件在其權責範圍內確認 → 寫進 `> [!research]-` 或 `> [!note]- 查證：…` callout。
  - **單一來源**：只代表某組織的立場 → 明確標出是誰說的。
  - **互相矛盾**：兩邊都寫，說明範圍或日期差異。
  - **查不到**：不寫成事實；需要時標「待驗證」。
- 推論要標明是推論，不能包裝成有來源的事實。

## 放置方式

查證內容放在它補充的對應語意段落旁，不混成講者原話：

```markdown
> [!research]- 外部查證
> 有範圍限制的已確認主張。
> [主要來源](https://...) · [獨立交叉確認](https://...)
```

用過的連結在文末的可摺疊「外部查證來源與使用範圍」集中保留，每筆包含：標題、網址、來源類型、查閱日期、支持了哪個主張。

## 停下來的條件

遇到以下情況，停下來告訴使用者，不要降低標準硬寫：

- 必要來源無法取得時暫緩該主張或該篇；不要反覆嘗試已知拒絕、付費或授權限制，也不能冒稱已核對。
- 高影響的主張（金額、法律、健康）查不到可靠來源。
- 只找得到低品質的二手來源。
- 來源互相矛盾，而且無法準確呈現。
