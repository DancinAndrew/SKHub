# Codex 專屬補充

## 輕量程式碼委派

- 對需求明確、範圍單一、低風險，且可以獨立完成的程式碼撰寫任務，優先考慮交給 `worker` subagent，並指定模型 `gpt-5.3-codex-spark`。
- 適用條件：目標檔案、預期行為與驗收方式均已明確，不需要架構決策或廣泛探索。
- 不適用於架構設計、複雜除錯、跨模組重構、資料遷移，以及涉及認證、安全、付款、秘密資訊或破壞性操作的任務。
- 若委派的協調成本高於直接完成的成本，主代理直接處理，不為了使用 subagent 而使用。
- 主代理仍負責提供清楚的任務邊界、檢查產出、執行必要驗證，並對最終結果負責。
- 若 `gpt-5.3-codex-spark` 不可用，不讓任務失敗；改由主代理執行或選用當下可用、適合簡單工作的快速模型。
